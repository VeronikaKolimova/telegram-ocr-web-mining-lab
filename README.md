# Telegram OCR & Text Mining Lab

Этот проект реализует полный цикл извлечения и анализа текста с изображений из Telegram с использованием Tesseract OCR. 
Разработан в рамках работы по курсу "Интеллектуальный анализ Web-данных".



##  Функциональность
- **Сбор данных:** автоматическая загрузка изображений из Telegram-канала через Telethon API
- **OCR-обработка:** распознавание текста с поддержкой русского и английского языков
- **Текстовая аналитика:** лемматизация, фильтрация стоп-слов, частотный анализ
- **Визуализация:** гистограммы, bar-чарты, круговая диаграмма

##  Технологии
- Python 3.10+
- Tesseract OCR
- Telethon
- Pillow (PIL)
- PyMorphy3
- Pandas, Matplotlib

##  Результаты
- Детальная статистика по каждому изображению
- Топ-15 наиболее частых слов после лемматизации
- Графики распределения текста и наличия/отсутствия текста
